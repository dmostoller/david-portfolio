# davidmostoller.com

Personal portfolio site showcasing projects, writing, and reading.

**Live:** [davidmostoller.com](https://davidmostoller.com)

## Stack

Astro 5 · Tailwind v4 · Vercel

## Features

- Hybrid rendering (SSR + static)
- Medium blog integration
- Dynamic OG images
- Dark mode
- View Transitions

## Development

```bash
pnpm install
pnpm dev
```
