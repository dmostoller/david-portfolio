# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

**Use pnpm, not npm.**

```bash
pnpm dev           # Start dev server
pnpm build         # Production build
pnpm check         # Type-check .astro and .ts files
pnpm format        # Format with Prettier
pnpm format:check  # Check formatting (what to run before a PR)
```

There's no linter or test suite; `pnpm check`, `pnpm format:check`, and `pnpm build` are the checks. `pnpm preview` doesn't work: the Vercel adapter doesn't support it. Prettier's config (`.prettierrc`) formats `.astro` files with tabs, single quotes, and 120 columns, and everything else with Prettier's defaults.

After adding new files, restart `pnpm dev`: the Tailwind v4 Vite plugin doesn't pick up classes from files created while the server is running.

## Architecture

This is an Astro 5 portfolio site with hybrid rendering deployed on Vercel.

**Stack:** Astro + Tailwind v4. No UI framework: components are `.astro`, client behavior is plain TypeScript in `<script>` tags or `src/scripts/`.

### Signal and Scope

- **Signal** is the site, at `/`, `/projects`, `/blog`, `/reading` (`src/layouts/BaseLayout.astro`). Its content lives in `src/content/profile.ts` (focus, path, stack, socials), `src/content/*.json`, and `src/lib/routes.ts` (page titles and descriptions).
- **Scope** is a hidden easter egg at `/scope`: a radio off the internet (`src/pages/scope/index.astro`, `src/layouts/ScopeLayout.astro`). Visitors reach it through the A/B switch in Signal's footer (`src/components/ui/ABSwitch.astro`); flipping it plays a static "crossing" (`src/scripts/crossing.ts`) and remembers which page to send them back to.
- Never show the word "Scope" to visitors. It's an internal name; the page and tab titles use `dbm`.
- Scope sets a canonical link to Signal's home page and is excluded from the sitemap. Unknown `/scope/*` paths render a 404 ("dead air").
- The radio is one dial from 0 to 11 with stations hidden in the static. Visitors land on "the internet" at 0 and the dial drifts to the first station; leaving tunes back to 0 and crosses over. Logging all seven stations puts a hidden one on the air: a portrait traced from the headshot.
  - `src/lib/scope/stations.ts`: each station's place on the dial, name, caption, links, and drawing. Drawings are polylines from plain functions of time, so the page can also render a still for visitors without JavaScript.
  - `src/lib/scope/portrait.ts`: generated by `node scripts/trace-portrait.mjs` from `src/assets/headshot.jpg`. Rerun it if the photo changes.
  - `src/scripts/scope/radio.ts`: mixes stations by how close the dial is, handles input (drag, wheel, ← →, `[` `]`, esc), the log of found stations, arriving, and leaving
  - `src/scripts/scope/beam.ts`: the phosphor canvas (trails, snow, the internet's chatter, the shake at eleven)
  - `src/scripts/scope/music.ts`: opt-in sound. Each station plays its own program on its own channel, faded in by how close the dial is and muffled until it's dead on, with soft static between stations and a bell chime on tuning in. `programs.ts` holds what each station plays (all in D major pentatonic, so neighbors never clash), `voices.ts` the little Web Audio instruments, and `sound.ts` the on/off setting and the crossing's static.
- With reduced motion, the radio skips the drift and the sweeps and draws still frames.

### Rendering Strategy

- `output: "server"` in astro.config.mjs enables SSR by default
- Home, Projects, and the radio are prerendered with `export const prerender = true`
- Writing and Reading render on request and send `Cache-Control` from `feedCacheControl()` (`src/lib/content.ts`) so Vercel's CDN caches them for an hour and serves stale while refreshing. Failed feeds are cached for only a minute.

### Project Structure

- `src/pages/` - Signal pages, the `scope/` radio and its 404, and `api/og.png.ts`
- `src/layouts/` - `BaseLayout.astro` (Signal: SEO meta, fonts, theme script, stripes, header, footer) and `ScopeLayout.astro`
- `src/components/signal/` - Signal section and page header
- `src/components/ui/` - ThemeToggle, Icon (inline Lucide SVGs from `icons.ts`), StripedBackground, ABSwitch
- `src/scripts/` - Client scripts bundled by Astro (the crossing, and the radio in `scope/`)
- `src/lib/` - Routes, content helpers, formatting (UTC dates, entity decoding), feed timeouts and Cache-Control, Medium and Inoreader clients, and the radio's stations in `scope/`
- `src/content/` - JSON data for projects, books, press, plus `profile.ts`
- `src/styles/global.css` - Tailwind v4 config with CSS variables for theming
- `scripts/` - one-off Node scripts (the portrait tracer)

### External Integrations

- **Medium:** `src/lib/medium.ts` - Fetches posts via the rss2json API; excerpts come from the first paragraph
- **Inoreader:** `src/lib/inoreader.ts` - Fetches the saved-articles RSS feed on the server (requires `INOREADER_RSS_URL` env var)
- **OG Images:** `src/pages/api/og.png.ts` - Dynamic Open Graph image generation using @vercel/og
- **Analytics:** `@vercel/analytics/astro` in both layouts

### Styling Conventions

- Tailwind v4 with OKLCH color variables defined in global.css
- Dark mode via `.dark` class on html element (toggled by ThemeToggle, which picks its icon with CSS so it's correct before scripts run)
- Uses shadcn/ui-style semantic color tokens: `background`, `foreground`, `primary`, `muted`, `border`, etc.
- Animations are CSS only (with `prefers-reduced-motion` fallbacks). Don't render content hidden until JavaScript runs.
- Signal's motion classes live in BaseLayout: `rise` on a page's wrapper (its blocks rise in one after another), `reveal` on a list (items fade up as they scroll in, where scroll-driven animations are supported; `[--reveal-shift:0px]` for a fade only), `press` on buttons, `live-dot` on "now" markers, and `arrow` on a `↗` inside a `group` link.
- `html` has `scrollbar-gutter: stable`, so pages line up the same whether or not they scroll.
- Format dates with `formatDate()` from `src/lib/format.ts`, which uses UTC so server and browser agree.

### Key Patterns

- Everything is plain Astro with no hydrated islands. Don't add React or another framework; add icons by copying Lucide shapes into `src/components/ui/icons.ts`.
- Cross-document view transitions via `@view-transition { navigation: auto; }` in BaseLayout; there's no `<ClientRouter />`. In Signal the header stays put, the nav underline slides, and `main` (`page`) fades out while the new page rises in. Theme changes and crossings drop all transition names (global.css).
- Security headers configured in vercel.json including CSP
